# Lingulet logo assets

The mark combines three ideas in one compact silhouette: a conversation bubble,
an open page, and an `L`. The vermilion tab represents the next small page or
lesson in a learner's daily loop.

## Palette

- Ink: `#25221d`
- Vermilion: `#b43b24`
- Paper: `#fffdf7`
- App background: `#f5f0e6`

## Files and usage

- `lingulet-logo.svg`: canonical scalable mark for MCP connections, website UI,
  and general brand use.
- `lingulet-logo-maskable.svg`: transparent safe-zone version for PWA maskable icons.
- `png/lingulet-logo-{16,32,48,64,128,192,256,512}.png`: transparent PNG exports.
- `chrome-extension/icons/icon-{16,32,48,128}.png`: Chrome Extension icons.

All distributed logo files have transparent backgrounds. Keep the mark upright,
preserve its colors, and do not add text inside the icon.
