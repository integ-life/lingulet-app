ステージ1 コース概要

  1. 1. Halo!

    5分

    あいさつをして、saya と kamu を覚えます

    halo · saya · kamu

    文法スキル: Saya Maya のような、「です」にあたる語のない文

  2. 2. Dia teman saya

    5分

    名前と友達を紹介します

    dia · teman · nama

    文法スキル: 名詞＋所有者（teman saya）。dia は男性にも女性にも使います

  3. 3. Ini apa?

    5分

    身の回りのよくある物の名前を言います

    ini · itu · apa

    文法スキル: 指示語 ini／itu の位置と、疑問詞 apa

  4. 4. Saya punya dua

    6分

    持っている物と基本的な数を伝えます

    punya · satu · dua

    文法スキル: 数＋名詞。名詞は複数形に変化しません

  5. 5. Saya suka

    5分

    好きな物を伝え、簡単に返事をします

    suka · tidak · ya

    文法スキル: tidak による動詞の否定

  6. 6. Makan dan minum

    6分

    毎日の基本的な欲求を伝えます

    makan · minum · mau

    文法スキル: 動詞は活用しません。mau＋動詞

  7. 7. Datang dan pergi

    6分

    人の基本的な移動を理解します

    datang · pergi · pulang

    文法スキル: 家に帰るときは pulang、datang は視点で決まります

  8. 8. Di mana?

    6分

    場所を尋ね、位置を理解します

    di · mana · sini

    文法スキル: 位置を表す di と、方向を表す ke

  9. 9. Tidak atau bukan?

    6分

    動作の否定と、何であるかの否定を区別します

    tidak · bukan · benar

    文法スキル: tidak と bukan の違い

  10. 10. Pagi Maya

    7分

    ミニストーリーでこれまでの表現をまとめて使います

    pagi · kemudian · rumah

    文法スキル: 時を表す語と、まとめの語順
