The reusable system

每张课程图都遵守同一套骨架

  1. 01

    身份锚点

    脸、发型、服装和随身物保持稳定；场景变化时不重新设计人物。

  2. 02

    单一动作

    每张图只承担一个可说清的行为：倾听、回答、提示、练习或庆祝。

  3. 03

    纸页世界

    纸纤维、墨线、扁平剪贴和克制颗粒延续 Lingulet 的叶片与翻页语言。

  4. 04

    教学边界

    图片提供语境但不泄露答案；文字、状态和无障碍语义仍由真实 UI 承担。
